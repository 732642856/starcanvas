### 2.2 各平台杀手锏功能

#### Seko — "工业化量产之王"
- **无限画布 + 多剧集记忆库**：自动继承前集角色/场景/道具，解决长线叙事的资产统一问题
- **Agent 批量 + 画布精修**：AI 批量跑分镜 → 人工精修 → 批量生成，效率质量兼顾
- **SekoClaw 龙虾入口**：24小时全自动无人值守生产
- **SekoIDX**：扩散模型高噪阶段引入负参考图，确保多镜头角色一致性
- **SekoTalk**：业内首个支持 2 人以上连续对口的方案
- **1 天产出 100 分钟**拟真人互动剧的量产能力

#### TapNow — "创作社区之王"
- **TapTV 工作流社区**：上万视频可一键克隆，看到完整提示词/参数/模型/工作流
- **Cinema Lab 电影级控制**：摄影机控制（景深/镜头语言）、多角度（可视化调整角色姿态）、火柴人动作参考
- **「@」技能调用**：画布中 `/` 即可调三视图、画面推演、九宫格、电影光影等
- **焦点编辑魔法棒**：精准修改画面细节
- **从灵感→发布的闭环**：一键发布到 TapTV 社区获取积分奖励

#### LibTV — "架构最先进的 Agent 友好型平台"
- **人虾共用体系**：人类用画布，Agent 用 Skill 调用，同一个平台两套入口
- **5 种基础节点**（文本/图片/视频/音频/脚本）：极简但覆盖全流程
- **节点打组→保存为工具箱模块**：可复用的封装工作流
- **OpenClaw Skill 集成**：Agent 可通过飞书等 IM 直接调用 LibTV 创作
- **定价激进**：年卡最低 39 折，订阅用户每月送 300 条最高等级视频额度

#### OiiOii — "动画创作全自动工厂"
- **7 个职业 Agent**：艺术总监/编剧/角色设计师/场景设计师/分镜师/音乐总监/产品设计师
- **149 种动画风格**：最丰富的动画风格库
- **多宫格分镜**：Agent 自动判断四宫格/九宫格，预览构图/角色站位/场景布局
- **"懒人画布"**：框选+输入即可，无需复杂连线，覆盖手搓/半自动/全自动三种模式
- **满血 Seedance 2.0**：不属于字节体系，但接入效果评价普遍高于小云雀

#### 小云雀 2.0 — "字节生态的短剧特化工具"
- **720°全景场景**：上传单角度图自动生成完整全景环境，镜头环绕/正反打一致
- **资产联动**：修改角色服饰 → 点击"应用到角色/场景" → 整个项目自动同步，99 集体量无需手动逐集替换
- **100+ 影视级画风**：真人分类下拆出 90 年代中国农村、美式复古、韩国冷淡风等
- **一句话 100 集剧本**：极低入场门槛
- **跳过剧本**：可从角色/场景/音频任意元素开始创作
- **光影精确控制**：方位/亮度/质感/色温可调
- ⚠️ **严重警告**：在 Seedance 2.0 各平台对比中，小云雀被视为"残血版"，效果远逊于即梦/OiiOii，废片率极高

### 7.1 TapNow Agent — 「画布里的执行导演」

**真实用户教程来源**：草堂大师兄《小白也能懂！超详细 TapNow Agent 教程》（腾讯新闻，2026.4.23）

**Agent 本质**：对话式 Agent，用户在聊天框扮演"导演"角色，Agent 负责在画布上自动执行——生成图片/视频、连接节点、写提示词。

**实际工作流**（以"中国武侠·竹林打斗"为例）：

| 阶段 | 用户操作 | Agent 行为 |
|------|----------|-----------|
| **定调** | 输入"定调你先给我一些参考" | 主动推荐《十面埋伏》《侠女》《影》《卧虎藏龙》等 4 部参考电影，8 张参考图放入画布 |
| **定角** | "生成女剑客形象，4个版本" | 调用 Banana Pro 生成 4 版角色，可指定正面/侧面/背面三视图 |
| **定角验证** | 点击「角色合规验证」 | 认证通过后才能生成真人视频（安全机制） |
| **分镜** | "竹林打斗，蒙面女偷袭，15秒" | 自动生成摄像机参数（景别/角度/运动/速度/焦点）+ 完整动作序列 |
| **场景** | 可选让 Agent 先生成场景图 | 场景图作为视频生成的参考锚点 |
| **视频** | 确认后点击生成 | Agent 自动写完整 Seedance 2.0 提示词（200+字，含运镜/光影/动作/时间轴） |

**Agent 写提示词的能力**（用户原文摘录）：

> "一镜到底，15秒，中国武侠打斗。0-3秒：红袍女剑客独自立于竹林深处...3-5秒：头顶竹叶剧烈晃动，蒙面黑衣女从上方竹林高空凌空跃下...13-15秒：烟雾散去，红袍女缓缓放下衣袖..."

用户评价："很专业，反正我是写不出来。"

**TapNow Agent 其他玩法**：
- 基于关键帧输出多角度图（正面/3/4侧面/背面/俯视/仰视/过肩/特写/远景，10个角度）
- 基于一张图批量生成组镜
- 一句话剧本→角色形象图→分镜图
- 上传剧本后 → "基于剧本设计角色形象"

**核心价值总结**（用户原话）：
> "TapNow Agent 最大的价值，不是帮你'一键出片'，而是把执行层面的复杂度拿走，让你把精力放回创意本身。"

### 7.2 LibTV Agent — 「人虾共用的 Skill 体系」

**真实用户教程来源**：

**Agent 接入流程**（4步上手）：

```
1. 部署 OpenClaw（飞书插件版/本地部署）
2. 安装 LibTV Skill：npx skills add libtv-labs/libtv-skills
3. 配置 Access Key：对话式授权或 export 环境变量
4. 下达指令：飞书对话框里发送"生成一个60秒漫剧..."
```

**Agent 实际执行过程**（冷逸实测）：

龙虾执行链：剧本创作 → 角色设计 → 分镜生成 → 视频制作 → 剪辑成片

> "左边是 OpenClaw 会话，右边是 LibTV 画布结果。有点遗憾的是，目前还不能实时看到龙虾创建工作流的过程，只能等任务结束后看最终的结果。"

**监控技巧**：
> "每隔 30 秒给我汇报一次创作进度" → 龙虾定时汇报进度

**真实效果评价**（用户原话）：
> "完成得还不错，声画同出，剧情连贯，人物主体的一致性也保持得不错。"
> "这种感觉就像是，我躺在床上刷视频一样，龙虾就是B站，而 libtv-skills 就是UP主，我只负责给UP主刷火箭、充Token，就会有源源不断的视频喂给我。"

**Skill 技术架构**：
```
libtv-skills/
├── SKILL.md           # 技能描述（OpenClaw 规范）
└── s/
    ├── _common.py     # 公共模块（鉴权/HTTP/API 封装）
    ├── create_session.py   # 创建会话/发送消息
    ├── query_session.py    # 查询进度
    ├── change_project.py   # 切换项目
    └── upload_file.py      # 上传素材到 OSS
```

**Agent 模式踩坑清单**（来自教程评论区）：
| 问题 | 详情 |
|------|------|
| 生成耗时长 | 30秒视频约需 5-10 分钟 |
| 字幕不准 | AI 生成字幕有提升空间 |
| 转场不流畅 | 画面之间过渡不够自然 |
| 背景元素不一致 | 同一物体不同镜头中形态变化 |
| 模型依赖 | 推荐 Gemini 3.1 / K2.5 / GLM-5-Turbo / Qwen3.5-Plus |
| 内测限制 | Access Key 需申请，算力为账号额度 |

**用户最终评价**（冷逸）：

### 10.2 关键发现

1. **Agent 正在成为标配**：Seko/TapNow/OiiOii/LibTV/小云雀已在 Agent 上全面布局，但方向截然不同——全自动黑箱 vs 可编程 Skill vs 参数化辅助
2. **LibTV 的"人虾共用"是唯一有想象空间的 Agent 架构**，但需技术基础
3. **TapNow 的 TapTV 社区是所有人羡慕的壁垒**：上万可克隆工作流 + 完整参数公开
4. **小云雀 2.0 的「@」资产调用 + 参数面板**是最接近专业影视制作流程的设计
5. **StarCanvas 的差异化机会**：全控制+可编程 Agent+FOSS，恰好填补"Agent 必须服从创作者"的空白区间

### 10.3 修正后的核心行动建议

| 优先级 | 行动项 | 新增依据 |
|--------|--------|---------|
| **P0** | 接入生成模型 | 无模型=无产出，所有竞品的 Agent 都依赖底层模型 |
| **P0** | 建立「星轨画廊」工作流社区 | TapNow 证明社区是最强壁垒，开源项目的天然优势——可公开完整工作流参数 |
| **P0** | 「@」资产调用系统 | 小云雀 2.0 证明这是专业创作者最核心的需求——在分镜里直接 @ 已设定的角色/场景/道具 |
| **P1** | Agent Skill 体系产品化 | LibTV 证明了 Skill 封装的价值，StarCanvas 已有技术基座（Film Crew 7 Agent + RunQueue）|
| **P1** | 参数化面板（光影/镜头/风格独立控制） | 小云雀 2.0 + TapNow Cinema Lab 证明"把专业维度从 prompt 拆出来"是趋势 |
| **P1** | 降低画布操作门槛（多选批量连线/自动布局） | Seko 的"选择+批量生成"和对画布"节点连线麻烦"的用户吐槽 |
